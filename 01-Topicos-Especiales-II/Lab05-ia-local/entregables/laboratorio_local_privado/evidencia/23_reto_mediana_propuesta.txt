Para agregar la función `mediana(valores)` al módulo `calculadora.py`, primero necesitamos definir una función que calcule la mediana de una lista de números. La mediana es el valor que separa a la mitad de los datos ordenados de manera ascendente. Si la cantidad de números es impar, la mediana es el valor del número en el índice central. Si es par, la mediana es el promedio de los dos valores centrales.

Aquí tienes el código para la función `mediana`:

```python
def mediana(valores):
    if not valores:
        raise ValueError("La lista de valores no puede estar vacía.")
    
    valores_ordenados = sorted(valores)
    n = len(valores_ordenados)
    
    if n % 2 == 1:
        # Cantidad impar de elementos
        return valores_ordenados[n // 2]
    else:
        # Cantidad par de elementos
        medio1 = valores_ordenados[n // 2 - 1]
        medio2 = valores_ordenados[n // 2]
        return (medio1 + medio2) / 2
```
